# Nuclr Homebrew tap

```sh
brew install --cask nuclrdev/tap/nuclr-commander
```

Nuclr Commander is a dual-pane file manager for developers: <https://nuclr.dev/>.

Commander updates itself, so `brew upgrade` skips it unless you pass `--greedy`.
`brew uninstall --zap nuclr-commander` also removes settings and plugins.

The cask is updated automatically on every Commander release. Please report
problems at <https://nuclr.dev/commander/feedback.html>.
